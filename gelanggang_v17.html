🔍 Google Custom Search (Gratis 100/hari)
Cari gambar langsung dari Google berdasarkan judul berita. Bebas CORS, langsung dari browser.

Cara setup (5 menit):
1. Buka console.cloud.google.com → cari Custom Search API → Enable → buat API Key
2. Buka programmablesearchengine.google.com → Add → isi nama bebas → centang Search the entire web → Create
3. Klik Customize → Search features → Image search: ON → Save
4. Copy Search engine ID → paste di bawah

🖼 Gambar Default (Cadangan Terakhir)
Dipakai kalau semua pencarian gambar gagal, supaya tidak ada berita tayang tanpa gambar.

Cara: WordPress → Media → Tambah Baru → upload gambar (misalnya logo/banner GelanggangNews) → klik gambarnya → lihat angka di URL post.php?post=1234 → isi angka itu di bawah. Kalau punya beberapa website, upload gambar yang sama di tiap website dengan ID yang sama, atau kosongkan saja.
